# ML Lifecycle — ML-001
Start with transparent anomaly rules and baselines, then evaluate learned models against labeled or credibly curated data. Maintain data provenance, event-time train/test separation and leakage checks.

Track dataset versions, feature definitions, model registry, explainability, calibration, precision/recall, false alarms and concept drift. Validate performance by operating conditions and relevant subgroups. No accuracy claims without test data and confusion-matrix evidence.

Serve versioned inference with fallback; shadow-test model changes before promoting. Include rollback, monitoring and human escalation.
