# Roadmap & release gates
Milestones are outcome-driven, not a promise of delivery dates.

| Gate | Deliverable | Exit criterion |
|---|---|---|
| G0 | Architecture baseline | Vision, BRD, SRS, C4, ADRs, threat model reviewed |
| G1 | Engineering foundation | Local docker stack, CI checks, API and event schema validation |
| G2 | Streaming vertical slice | Connector → Kafka → processing → lakehouse → dashboard replayed |
| G3 | Governed AI | Evidence-linked investigation, prompt-injection and permission tests |
| G4 | Reliability | Load, chaos/recovery, restore, monitoring and cost report |
| G5 | Deployment | Reproducible cloud environment, rollback and operational sign-off |

### Priorities
P0: data contract, security boundaries, audit, tests, monitoring. P1: multilingual UX and ML baseline. P2: multi-domain expansion and advanced autonomous optimization.

Definition of production-grade: verified SLOs, threat assessment, operational owners, incident process, backup tests, deployment evidence, and real-user acceptance. No milestone is considered complete solely because its documentation exists.
